# Study Planner

## Project Description

Study Planner is a simple website that helps students organize their study tasks and schedule.

## Purpose

The purpose of this project is to help students manage their study time and keep track of their school tasks.

## Main Features

* Add and organize study tasks
* Organize tasks by subject
* Set deadlines for tasks
* Mark completed tasks
* View the study schedule
